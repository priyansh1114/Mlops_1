1.  Lab Storyline — “It Works on My Laptop”
Your Lab 1 work was a hit. The retention team asked Priya to score last week's customers with the champion model — and it crashed on her machine with a scikit-learn version error. Her laptop has sklearn 1.2; you trained on 1.5. Two hours were lost proving the model wasn't broken, the environment was.
Your team lead makes two decisions. First: the model runs inside a Docker container from now on, so the environment travels with it — that is Part A. Second: the weekly retrain-validate-register cycle you have been running by hand becomes an orchestrated pipeline that runs the same way every time, with a quality gate so a bad model can never silently become champion — that is Part B, with Apache Airflow as the orchestrator.
Continuity:  You are packaging the exact @champion from Lab 1 and automating the exact scripts you wrote there. Nothing is thrown away; it is industrialized.
2.  Objective
To package the CartVista churn model as a self-contained Docker image that scores customer batches identically on any machine, and to orchestrate the train → validate → register lifecycle as an Airflow DAG with an explicit quality gate.

Reason about idempotency: why every task must be safe to re-run.

5.  Part A — Containerize the Champion
Step A1 — Export the champion out of the registry
A container should not need your mlflow.db. This script copies the champion's artifacts into a plain folder the image can bake in.
  export_champion.py
"""Export @champion artifacts to ./model_export for Docker packaging."""
import shutil, pathlib, mlflow
from mlflow import MlflowClient
 
mlflow.set_tracking_uri("sqlite:///mlflow.db")
client = MlflowClient()
mv = client.get_model_version_by_alias("cartvista-churn", "champion")
print(f"Exporting cartvista-churn v{mv.version} (run {mv.run_id[:8]})")
 
dst = pathlib.Path("model_export")
if dst.exists(): shutil.rmtree(dst)
local = mlflow.artifacts.download_artifacts(
    artifact_uri=f"runs:/{mv.run_id}/model", dst_path=".")
shutil.move(local, dst)
print(f"Model exported to {dst}/ -- contents: {[p.name for p in dst.iterdir()]}")

"""Container entrypoint: score a CSV of customers with the baked-in model."""
import sys, pandas as pd, mlflow.pyfunc
 
IN_PATH  = sys.argv[1] if len(sys.argv) > 1 else "/data/input.csv"

Step B2 — The pipeline DAG with a quality gate
Create the dags folder and the DAG file. The DAG automates your Lab 1 loop: refresh data → train two candidates → validate the best against a quality bar → only then promote it to champion. The gate task is the culture change: no human can skip validation, because promotion is downstream of it.
  airflow_home/dags/cartvista_pipeline.py
"""CartVista weekly retrain pipeline: data -> train x2 -> gate -> promote."""
from datetime import datetime
import subprocess, json, pathlib
from airflow.decorators import dag, task
 
PROJECT = pathlib.Path(__file__).resolve().parents[2]   # cartvista-mlops
AUC_GATE = 0.72          # a model below this bar must NOT become champion
 
def run(cmd):
    r = subprocess.run(cmd, cwd=PROJECT, shell=True,
                       capture_output=True, text=True)
    print(r.stdout, r.stderr)
    r.check_returncode()
    return r.stdout
 
@dag(schedule=None, start_date=datetime(2026, 1, 1), catchup=False,
     tags=["cartvista"])
def cartvista_weekly_retrain():
 
    @task
    def refresh_data():
        run("python generate_data.py")
 
    @task
    def train_logreg():
        run("python train_tracked.py --model logreg --C 1.0")
 
    @task
    def train_rf():
        run("python train_tracked.py --model rf --n-estimators 200 --max-depth 8")
 
    @task
    def validate_best() -> float:
        import mlflow
        from mlflow import MlflowClient
        mlflow.set_tracking_uri(f"sqlite:///{PROJECT}/mlflow.db")
        client = MlflowClient()
        exp = client.get_experiment_by_name("cartvista-churn")
        best = client.search_runs([exp.experiment_id],
                order_by=["metrics.test_auc DESC"], max_results=1)[0]
        auc = best.data.metrics["test_auc"]
        print(f"Best AUC this cycle: {auc:.4f} (gate: {AUC_GATE})")
        if auc < AUC_GATE:
            raise ValueError(f"Quality gate FAILED: {auc:.4f} < {AUC_GATE}")
        return auc
 
    @task
    def promote():
        run("python register_model.py")
 
    d = refresh_data()
    gate = validate_best()
    d >> [train_logreg(), train_rf()] >> gate >> promote()
 
cartvista_weekly_retrain()

8.  Troubleshooting
Symptom
Fix
docker: permission denied
Linux: add yourself to the docker group (sudo usermod -aG docker $USER) and re-login. Windows/macOS: ensure Docker Desktop is running.
Airflow UI empty / DAG missing
AIRFLOW_HOME not exported in this terminal, or the file has a syntax error — run  python airflow_home/dags/cartvista_pipeline.py  to check, then wait 30 s.
Port 8080 already in use
airflow standalone respects  AIRFLOW__WEBSERVER__WEB_SERVER_PORT=8081  (export before starting).
Tasks fail with 'mlflow.db not found'
The DAG resolves PROJECT relative to the dags folder — airflow_home must live INSIDE cartvista-mlops as shown, or adjust PROJECT.
Windows: pip install airflow fails
Expected — Airflow does not support native Windows. Do all of Part B inside WSL2 Ubuntu.
Volume mount shows empty /data
Quote the mount and use the shell-correct pwd form from Step A4; on Docker Desktop confirm the drive is shared (Settings → Resources → File sharing).
